Replit Agent System Prompt: Agentic GTM Factory
Project Overview:
Build a "3-Stage Agentic GTM Operating System" that transforms raw market data into high-intent, personalized outreach. The platform must be a Next.js (App Router) frontend with a FastAPI (Python) backend using LangGraph for multi-agent orchestration.

Tech Stack Requirements:

Frontend: Next.js, Tailwind CSS, Shadcn/UI (Dark Mode, Sidebar Layout).

Backend: FastAPI, LangGraph, Pydantic (for data validation).

Database: Replit PostgreSQL (Structured data) + Pinecone (Vector storage for Pattern Recognition).

Integrations: OpenAI (GPT-4o mini), SerpAPI (Market Intelligence), Apollo/Hunter (Enrichment), and Instantly.ai (Outreach).

Module Requirements for Initial Build:
Stage 1: Strategy & Discovery (S1)
ICP & Persona Agent: Create an input canvas for "Product Details." Use GPT-4o mini to generate a JSON output defining: Firmographics, 3 Buyer Personas (Champion, Blocker, Economic Buyer), and Pain Point Maps.

Industry Segmentation: Agent must cluster inputs into NAICS-coded verticals.

Buying Center Mapping: Visualize a "Stakeholder Graph" showing how these personas interact during a deal.

Stage 2: Intelligence & Scoring (S2)
Signal Detection Agent: Use SerpAPI to search for "Buying Triggers" (Funding, Hiring, Tech stack changes) based on the S1 ICP.

Lead Scoring Engine: Create a logic that ranks leads (Tier 1, 2, 3) based on the "Pattern Recognition Agent" (comparing signals to historical "hot" profiles).

Enrichment Dashboard: A table view showing lead names, verified emails (via Hunter/Apollo), and LinkedIn URLs.

Stage 3: 3-Channel Execution (S3)
Messaging Agent: Generate multi-touch sequences (Email/LinkedIn). The copy must be grounded in the "Problem-Solution Map" from S1.

SDR Copilot: A "Next-Best-Action" feed that monitors engagement (opens/clicks) and suggests manual tasks like "Call Now" or "Send LinkedIn Invite."

Development Instruction:

Initialize: Start by setting up the PostgreSQL schema for "Strategies," "Accounts," and "Signals."

S1 First: Build the "Onboarding Workspace" where I can input my product info and see the ICP Agent generate the Strategy JSON.

UI Vibe: The design should be a high-end, dark-themed SaaS dashboard. Use a sidebar for navigation between Stage 1, Stage 2, and Stage 3.

How to "Vibe Code" This in Steps
The Replit Agent works best when you guide it through the "Flow" rather than asking for the whole house at once. Once you paste the prompt above, follow up with these specific instructions as it builds:

Step 1: "Build the S1 Onboarding form and the LangGraph state machine that handles the ICP Agent generation."

Step 2: "Now create the S2 Lead Table. Add a 'Search for Leads' button that uses the Apollo API structure to fetch data based on the S1 ICP."

Step 3: "Build the 'Signal Detector' UI. Show a live feed of news and hiring alerts for the companies in our Lead Table."

Step 4: "Finally, build the S3 Messaging view. Show the email sequence generated by the AI for a specific Tier 1 lead."
