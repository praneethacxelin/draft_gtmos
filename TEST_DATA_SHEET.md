## Validation Checklist (Run for Each Profile)

### Step 1: Create Profile & Fill Discovery
- [ ] Create product profile (name only)
- [ ] Fill all 15 discovery questions
- [ ] Verify auto-save works (no manual save needed)
- [ ] Verify active profile dropdown syncs when viewing this profile

### Step 2: Run S1 Pipeline
- [ ] Click "Run S1" — verify SSE streaming works
- [ ] **ICP**: Check geographies, org size, industries match discovery answers
- [ ] **Personas**: Verify Champion/Buyer titles match discovery inputs
- [ ] **Problems**: Verify pain points map to actual market problems
- [ ] **NAICS**: Check NAICS codes are relevant (not generic "Software Publishing")
- [ ] **Stakeholders**: Verify buying committee graph makes sense
- [ ] **Use Cases**: Check they're specific to the product, not generic

### Step 3: Run Market Sizing
- [ ] Click "Run Market Sizing"
- [ ] **TAM**: Should reference a real industry report (Gartner, Grand View Research, etc.)
- [ ] **SAM**: Should narrow down to the specific segment (not just "global software")
- [ ] **SOM**: Should be realistic for the company stage
- [ ] **Methodology**: Should cite the search snippets and explain the math
- [ ] **Sources**: Should have 2-4 verified sources with real URLs

### Step 4: Discover Leads
- [ ] Click "Discover Leads"
- [ ] If using Apollo: verify leads match the ICP (right titles, right company sizes, right geos)
- [ ] If demo mode: verify demo data looks realistic for the vertical
- [ ] Check lead scores make sense (Tier 1 should be the best matches)

### Step 5: Run Signals
- [ ] Click "Run Signals"
- [ ] **Actionable format**: Each signal should be `[Fact] - [Why it matters]`
- [ ] **Relevance**: Signals should be about the actual target companies (not random companies)
- [ ] **Signal types**: Should see a mix of funding + hiring signals
- [ ] **No vague titles**: Should NOT just be the raw search result title

### Step 6: Generate Outreach
- [ ] Select a Tier 1 contact → Generate sequence
- [ ] **Personalization**: Email should reference the persona's pain points and role
- [ ] **Multi-channel**: Should include email + LinkedIn + call steps
- [ ] **Subject lines**: Should be specific, not generic "Follow up"

## Git Push Troubleshooting

If you encounter this error:
```
error: RPC failed; curl 52 Recv failure: Connection was reset
fatal: the remote end hung up unexpectedly
```

**Fix**: Increase the Git HTTP buffer and retry:
```powershell
git config --global http.postBuffer 524288000
git push
```

If it still fails, try pushing in smaller commits or using SSH instead of HTTPS:
```powershell
# Check current remote
git remote -v

# Switch to SSH if available
git remote set-url origin git@github.com:USERNAME/REPO.git
git push
```
